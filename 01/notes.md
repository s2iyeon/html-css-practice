## 1강 - HTML 기초와 개발환경 셋팅

### HTML 파일
- `.html`로 끝나는 파일은 모두 HTML 파일이고, 모든 웹페이지는 HTML 파일로 만들어진다
- 메인 페이지 파일명은 보통 `index.html`로 짓는다

### HTML 기본 템플릿
- VSCode에서 `!`를 입력하고 `Tab`(또는 `Enter`)을 누르면 기본 템플릿이 자동으로 생성된다
- 모든 HTML 파일은 항상 이 템플릿부터 작성하고 시작한다

### Live Server
- VSCode 확장 프로그램 Live Server를 쓰면 코드를 수정할 때마다 브라우저에 실시간으로 반영된다
