## 2강 - HTML 기본 태그

### 태그
- HTML에서는 글을 그냥 쓰지 않고 태그로 감싸서 작성한다
- `<`와 `>`로 둘러싸인 것을 태그라고 부른다
- 대부분의 태그는 여는 태그와 닫는 태그(`</p>`)가 한 쌍이다

### 글과 제목
- `<p></p>`: 본문(paragraph)을 적을 때 사용한다
- `<h1></h1>` ~ `<h6></h6>`: 제목(heading)에 사용하며 숫자가 클수록 글자 크기가 작아진다
- 글 제목은 `<h1>`, 본문은 `<p>`를 사용한다

### 태그를 쓰는 이유
- HTML은 자료가 어디에 어떻게 배치되어 있는지 표현하는 마크업 언어이다
- 태그를 보면 글자의 용도와 목적을 바로 파악할 수 있다
- 모든 요소를 태그 안에 넣어 작성하면 웹 표준을 잘 지킨 것이다

### 이미지
- `<img src="이미지경로">`로 사용한다
- `src`는 속성이며 source(출처)의 약자이다
- `img`는 닫는 태그가 없다

### 버튼
- `<button></button>`: 태그 안에 버튼 이름을 적는다

### 링크
- `<a href="주소">링크</a>`로 사용한다
- `a`는 anchor의 약자이다
- `href`는 속성이며 hypertext reference의 약자이다

### 리스트
- `<ul>`: unordered list의 약자이며 순서 없는 목록이다
- `<ol>`: ordered list의 약자이며 번호가 있는 목록이다
- `<li>`: list item의 약자이며 목록의 항목이다
- `ul`이나 `ol` 안에 `li`를 넣어 사용한다 (예: `<ul><li>리스트</li></ul>`)

### 속성과 중첩
- 일부 태그(`img`, `a` 등)는 속성을 적을 수 있다
- 태그 안에 다른 태그를 넣을 수 있다 (예: `ul` 안의 `li`)

### 숙제
- "안녕하세요 이동하기"에서 "이동하기"를 누르면 네이버로 이동하게 만들기
- `<p>안녕하세요<a href="https://naver.com">이동하기</a></p>`
