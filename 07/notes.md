## 7강 - 레이아웃 만들기 2 : 귀찮은 inline-block

### 주석
- 주석은 "이 코드는 해석하지 말아달라"는 뜻이다
- 필기나 메모 용도로 쓸 수 있고, 협업할 때도 유용하다
- 작업 중에 특정 요소를 잠시 안 보이게 할 때도 사용한다
- HTML 주석은 `<!-- 내용 -->`, CSS 주석은 `/* 내용 */`이다
- 맥에서는 `Cmd + /`로 선택한 줄을 주석 처리한다

### display: inline-block
- 6강에서는 `float`로 가로 배치를 했고, 이번에는 `display: inline-block;`으로 한다
- `display: block`은 한 행 전체를 차지하고, `inline-block`은 자기 크기만큼만 차지한다
- `inline-block`은 요소를 글자처럼 취급해서 한 줄에 나란히 놓을 수 있다
- 나란히 놓을 박스(`left-menu`, `right`) 모두에 `display: inline-block;`을 준다

### inline-block의 공백 문제
- 글자처럼 취급되기 때문에 HTML 코드에서 태그 사이의 줄바꿈이나 스페이스가 띄어쓰기 한 칸(약 4px)으로 인식된다
- 예: 800px 안에서 20% + 80% 박스를 놓으면 160px + 640px + 띄어쓰기 약 4px = 804px가 되어 두 번째 박스가 아래 줄로 내려간다
- 해결 방법 1: 태그 사이를 붙여 쓴다 (`</div><div>`). 다만 엔터를 칠 수 없어서 불편하다
- 해결 방법 2: 태그 사이를 주석으로 이어서 공백을 없앤다 (코드가 지저분해 보인다)
- 해결 방법 3: 부모 태그에 `font-size: 0;`을 준다. 띄어쓰기도 글자라서 크기가 0이 되어 공백이 사라진다
- 글자를 쓰는 자식 요소에는 `font-size`를 다시 지정해야 한다
- 상속된 스타일은 요소에 직접 준 스타일보다 우선순위가 낮아서, 자식에서 원하는 크기로 다시 지정할 수 있다
- 이런 불편 때문에 가로 배치는 `float`가 더 편하다는 의견도 있다

### 박스 안에 글자를 넣으면 배치가 어긋나는 문제
- `right` 박스 안에 `<p>안녕하세요</p>`를 넣으면 박스 배치가 어긋난다
- `left-menu`에 `vertical-align: top;`을 주면 해결된다
- `vertical-align`은 상하 정렬 속성이며 `top`은 위쪽, `bottom`은 아래쪽으로 보낸다
- `display`가 `inline` 또는 `inline-block`인 요소에만 적용된다

### 어긋나는 이유 : 베이스라인
- 영어 공책의 밑줄처럼, 글자가 올라타는 가상의 선을 베이스라인이라고 한다
- `inline-block` 요소는 글자처럼 취급되어 이 베이스라인에 맞춰 정렬된다
- 글자가 들어 있는 박스는 글자의 베이스라인에 맞춰지고, 비어 있는 박스는 박스의 맨 아래가 베이스라인에 맞춰진다
- 그래서 글자가 있는 박스와 비어 있는 박스를 나란히 두면 높이 기준이 달라 어긋난다
- `vertical-align: top;`을 주면 베이스라인 대신 위쪽을 기준으로 맞춘다
